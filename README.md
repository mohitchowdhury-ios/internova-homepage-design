# InternNova Homepage Redesign

A responsive homepage redesign concept for InternNova, built with HTML, CSS, and vanilla JavaScript.

## Run locally
1. Extract the project folder.
2. Open `index.html` in a browser, or use VS Code Live Server.
3. Check desktop, tablet, and mobile layouts.

## Features
- Responsive navigation with mobile menu
- Hero section and custom CSS illustration
- About, internship domains, process, learning, workshops, FAQs, CTA, and footer
- Scroll reveal animations with reduced-motion support
- Interactive accordion FAQs
- Links to InternNova's official internship pages

## Publish
Upload the project to a GitHub repository, then deploy it using GitHub Pages or Netlify. Replace the repository and live-site links in your submission with your own URLs.

This is an independent redesign concept, not an official InternNova website.
